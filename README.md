#File Integrity Checker

This project is created for CODTECH Internship Task-1.

## Description
A Python tool that checks file integrity by calculating and comparing hash values using hashlib.

## Features
- Generates SHA-256 hash of a file
- Detects file modification
- Simple and secure

## Technologies Used
- Python
- hashlib library

## How to Run
1. Install Python
2. Run the script:
   python integrity_checker.py
3. Enter the file path when asked
